# Screen "2025-4"

* 8 panels, twinned in groups of 2
* PowerCon, labelled 110V! PSU has no markings so it's unclear if it supports 230V, but it probably does?
* Unidentified receiver card, but I'd put money on it being DBStar or Linsn

Tile PCBs are visible and driver ICs are MBI5050GP ([datasheet](../../../datasheets/MBI5050%20Datasheet.pdf)).
This seems quite similar to the MBI5153 in the [DMG1083](../../tiles/dmg1083/_index.md).

This one is likely best harvested for tiles.
